# Envy Hair Cut Design website (demo)

A demo website for a hair salon in Taman Melawati, Kuala Lumpur. It is plain HTML, CSS and JavaScript with no build step.

This is not the live site. Bookings don't reach the salon, prices are placeholders, and most photos are stock images from Unsplash.

## Editing

- Shop details, prices, hours and reviews: `js/config.js`
- English and Bahasa Melayu text: `js/i18n.js`
- Colours and fonts: top of `css/styles.css`

## Before launch

1. Confirm the prices.
2. Add the salon's number to `whatsapp` in `js/config.js`.
3. Replace the stock photos.
4. Set `isPlaceholder` to `false` in `js/config.js`.
5. Remove the `noindex` line from `index.html`.
